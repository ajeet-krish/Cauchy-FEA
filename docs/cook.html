Cook's Membrane

A trapezoidal panel under distributed shear load. Classic benchmark for testing Q4 element bending performance and shear locking behavior. Reference: Cook, Malkus, Plesha "Concepts and Applications of FEA".

Problem Setup

ParameterValue
Length (x)48 mm
Left height (fixed)44 mm
Right height (loaded)60 mm
Thickness1 mm
Young's modulus (E)1.0 MPa (normalized)
Poisson's ratio (ν)1/3
Total shear load1.0 N (distributed on right edge)
Mesh32 x 32 Q4 elements
SolverConjugate Gradient (2178 DOFs)

Boundary Conditions

Clamped: ux = uy = 0 on left edge (x = 0)
Loaded: Distributed shear Fy = 1.0 N / (ny+1) per node on right edge

Discussion

The tip displacement ratio of ~0.53 to the reference value indicates significant shear locking. This is expected for full-integration Q4 elements on a trapezoidal mesh with combined bending and shear loading. The standard Cook's membrane benchmark uses a traction-based load (1/16 N/mm per unit area), which differs from the point-load distribution used here. Refining the mesh or using reduced integration would improve agreement with the reference solution.

This case is particularly valuable for demonstrating the shear locking limitation of bilinear quad elements. It shows that understanding element behavior is as important as implementing the solver correctly.
