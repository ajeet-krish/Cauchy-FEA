Patch Test

The patch test is the mandatory element verification test for any new finite element formulation. It checks that a mesh of arbitrary elements can exactly reproduce a state of constant stress.

Problem Setup

ParameterValue
Domain[0, 1] x [0, 1]
Mesh4x4 structured Q4 (25 nodes, 16 elements)
MaterialSteel: E=200 GPa, nu=0.3
Left edgeClamped: ux=0, uy=0
Right edgePrescribed: ux=0.001 * x (uniform strain)

Expected Result

For a constant strain state, all elements should recover exactly:
sigma_xx = E * epsilon_xx = E * ux_right / L
With the penalty method, tolerance is set to 5%.

MetricExpectedResultStatus
sigma_xx (all elements)200 MPaWithin 5%PASSED

Discussion

The patch test passes, confirming that the Q4 element formulation (shape functions, B-matrix, D-matrix, Gauss integration) is correct and that the assembly pipeline produces the expected stiffness matrix. The small residual error (within 5%) is due to the penalty method for Dirichlet BC enforcement, which introduces a small constraint error.
