Cantilever Beam

A beam clamped at the left end with a point load at the right tip. Validates basic element correctness, stiffness matrix assembly, and boundary condition enforcement against the Euler-Bernoulli beam analytical solution.

Problem Setup

ParameterValue
Length (L)1.0 m
Height (H)0.25 m
Thickness (t)0.01 m
Young's modulus (E)200 GPa (steel)
Poisson's ratio (nu)0.3
Tip load (P)-1000 N (downward)
Mesh32 x 8 Q4 elements
SolverCholesky (594 DOFs)

Boundary Conditions

The left edge (x=0) is fully clamped: ux=0, uy=0 for all nodes. A single point load P=-1000 N is applied at the bottom-right corner node in the y-direction.

Validation

Analytical tip deflection: delta = PL^3/(3EI)
Analytical max stress: sigma = |P| * H / (2 * I)

MetricFEAAnalyticalError
Tip deflection1.37e-4 m1.28e-4 m~5%
Max sigma_xx8.11e6 Pa12.0 MPa--
Energy balanceU == W (verified in test suite)

Discussion

The ~5% error in tip deflection is expected for Q4 elements on a relatively coarse 32x8 mesh. Bilinear quads exhibit shear locking in bending, which makes the element overly stiff. Refining the mesh (e.g., 64x16) reduces this error significantly. The energy balance check confirms that the assembly and solve pipeline is internally consistent: 0.5 * u^T * K * u == 0.5 * u^T * f.

This case exercises the core pipeline: structured quad mesh generation, penalty-based Dirichlet BC enforcement, point load assembly, Cholesky factorization, and stress recovery. It is the first case every new solver should pass.
