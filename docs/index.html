Cauchy: 2D Finite Element Structural Solver

A header-only C++20 solver implementing bar and bilinear quad (Q4) elements with COO/CSR sparse assembly, Cholesky and Conjugate Gradient solvers, and Von Mises stress recovery. Built as a portfolio centrepiece for mechanical and aerospace engineering roles.

Validated on 6 benchmark cases

What Is Cauchy?

Cauchy is a from-scratch 2D finite element solver. It solves static structural problems -- beams, plates, trusses, stress concentrations -- using first-principles element formulation, sparse linear algebra, and direct/iterative solvers. Every line of code is written to be read and understood.

The solver handles plane stress and plane strain, supports both bar (truss) and Q4 (bilinear quad) elements, and recovers element-centered stress fields with Von Mises and principal stress computation. It is validated against closed-form analytical solutions and published benchmark data.

Key Features

Bar + Q4 Elements

Two-node truss elements and 4-node bilinear quads with full 2x2 Gauss integration.

Dual Solvers

Cholesky direct solver for small/medium systems. Conjugate Gradient with Jacobi preconditioner for large sparse systems.

Sparse Assembly

COO format for natural element assembly, converted to CSR for fast matrix-vector products.

Stress Recovery

Element-centered stress, node-averaged smoothing, Von Mises and principal stresses.

Mesh Convergence

h-refinement studies with GCI (Grid Convergence Index) per ASME V&V 20-2009.

OpenMP Parallel

Element assembly and stress recovery loops parallelized with OpenMP.
